### CRUD Action-Permission Gating

Commit: `db8f251`

`feat(core): gate crud create and row actions on an explicit permission`

Five files in `src/core/components/crud/` + `src/core/types/crud.ts`. Adds an
optional `actionPermission` prop to `EnhancedCrudContainer`, threaded through
`TableView` → `ClickableTableRow` / `ClickableCard`. When set, the create
button and each row action gate on that one permission string instead of the
`${module}.${action}` pair. Standalone and purely additive — existing callers
pass `module` and are untouched — so it is committed first, ahead of the two
screens that use it. No changelog entry: no user-visible behaviour on its own.
