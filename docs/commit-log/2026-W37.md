## Friday — 2026-09-11

### Customer Profile Personal Details Section

Commit: `fab5399`

`feat(cms): show personal details on the customer profile`

`CustomerPreview.tsx` only. Adds a Personal Details block to
`CustomerPreviewData` — title, first/middle/last name, citizen ID, date of
birth, blood group, gender — gated per-field on the existing customer form
config the same way the surrounding sections already are. Citizen ID and DOB
still route through `usePiiMasker`; DOB is only passed to `formatDate` on the
branch where the viewer actually holds the unmasked value, so a masked
`••/••/1990` string is never fed to a date formatter. Purely additive;
`tsc -b` passes on the tree.

**Known gap, not fixed in this commit:** the new `userform.*` translation keys
(`userform.personal`, `userform.title`, `userform.firstName`, …) do not exist
in `public/i18n/{en,th,cn}.json`. The i18n loader (`src/core/utils/i18n.ts`)
falls back to the raw key string when a key is missing, so these labels
currently render untranslated. Equivalent, already-translated keys exist under
`customerConfigure.fields.*` but this change does not reference them. Left
as-is — out of scope for this documentation run to make an unreviewed feature
edit.
