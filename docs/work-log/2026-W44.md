## Wednesday — 2026-10-28

### Assignment Rules Redesign (Automatic Mode & Routing Criteria)

**Spending Hour:** 4.5 hr.

**Activity**

- ปรับ contract ของ Assignment Rules จาก routing method ตัวเดียว เป็น mode Automatic/Manual + routing criteria หลายตัว (skill, location, department, availability, case type) พร้อมตัวเลือกรวมเงื่อนไขแบบ AND/OR
- เพิ่มการเลือก case sub-type สำหรับ criteria ประเภท case type พร้อม Select All / Deselect All และ validation ว่าต้องเลือกอย่างน้อยหนึ่ง criteria ใน Automatic mode
- เพิ่ม Advanced Options panel แบบพับได้ (require all skills, respect shift, suggest by workload, allow override) ตาม mode
- ปรับ default, merge logic และ mock stub ให้รองรับโครงสร้างใหม่
- ปรับ MultiSelect กลางให้รองรับ controlled mode และปิดเมื่อคลิกนอก dropdown
- เพิ่มคำแปลทั้ง 3 ภาษา (catalog ถูก re-serialize ทำให้มีการจัด format บางส่วนในไฟล์แปลด้วย)

**Scope / Context**

- อยู่ในหน้า Organization / System Settings ส่วน Assignment Rules ซึ่งยังเป็น configuration-only ตาม FE-first contract (`/organizations/{orgId}/assignment-rules`) ที่ backend ยังไม่ได้ทำ และยังไม่มี routing engine ใช้ค่าเหล่านี้

**Outcome**

- admin กำหนดกฎการมอบหมายได้ละเอียดขึ้นและใกล้กับ requirement จริง พร้อมให้ backend ต่อเชื่อมได้โดย FE ไม่ต้องแก้มาก

### Batch Staff Assignment from Case Map

**Spending Hour:** 3.5 hr.

**Activity**

- สร้าง module กฎการเลือกสำหรับ batch assign (จำกัดสูงสุด 5 คน, เงื่อนไข select all, การ prune selection เมื่อ roster เปลี่ยน) พร้อม unit test ใช้ร่วมกันทั้งหน้าต่าง Assign Officer และ staff group panel บนแผนที่
- เพิ่ม checkbox, Select all และปุ่ม Assign selected ใน staff group panel ของ case map และเชื่อม handler ใน Case Detail ให้ส่ง dispatch ทีละคนผ่าน endpoint เดิมแบบ sequential แล้ว refetch ครั้งเดียว
- แก้ปัญหาหน้าต่าง Assign Officer ล้าง selection กลางคันเมื่อ roster ถูก refetch หลังแต่ละ dispatch
- เพิ่มคำแปลข้อความ limit และปุ่มทั้ง 3 ภาษา

**Scope / Context**

- dispatcher ต้องการมอบหมายเจ้าหน้าที่หลายคนที่อยู่ในจุดเดียวกันบนแผนที่ได้ในครั้งเดียว
- ตัดสินใจใช้ single-assignment endpoint เดิมแบบหลาย request ไปก่อน ส่วน batch endpoint เป็นงานในอนาคต

**Outcome**

- มอบหมายเจ้าหน้าที่ได้สูงสุด 5 คนต่อครั้งทั้งจากแผนที่และหน้าต่าง Assign Officer ด้วยกฎเดียวกัน
- selection ไม่หายระหว่างการ assign อีกต่อไป

**Daily Estimated Effort:** 8 hr.
