### CC Super App Authentication Architecture — Internal Discussion

**Spending Hour:** 2 hr.

***Activity***

- อภิปรายและบันทึกสถาปัตยกรรมการยืนยันตัวตนของ CC Super App ไว้ใน `docs/CC-Super-App-Authentication-Architecture.md`
- สรุป solution 1: Standard Authentication (Keycloak) — OAuth2.1 ผ่าน GraphQL → CC SuperApp RESTful API → Keycloak โดยรับ username/password/organization และส่งออก access token + user profile
- สรุป solution 2: Genesys Authentication (integration กับ 3rd party Genesys Cloud) — 4 ขั้นตอน:
  1. Authentication & prepare data ผ่าน SDK `purecloud-platform-client-v2` (v185.0.0, Node.js v20.10.0) ด้วย Authorization Code + PKCE สำหรับ browser-based app โดย callback URL กำหนดเป็น `https://skyai-cloud-cc-stg.one-sky.ai/genesys-authen?interactionId=[uuid]`
  2. Get current agent extension ผ่าน Genesys Cloud API (`GET /api/genesys-line-extension`)
  3. Authentication to CC SuperApp ผ่าน bypass login (`GET /api/genesys-bypass-login`) โดยส่ง Genesys token + organization
  4. Redirection ไปหน้า CRM Case Creation พร้อม query params: `phoneno`, `DNIS`, `ext`, `chtype`, `chname`, `queue`
- บันทึก Genesys SDK PKCE call APIs reference สำหรับดึงข้อมูลหลัง login: user profile (`/api/v2/users/me`), organization (`/api/v2/organizations/me`), station details (`/api/v2/stations/{stationId}`), conversation (`/api/v2/conversations/{interactionId}`), call details (`/api/v2/conversations/calls/{interactionId}`)
- บันทึก schema ของ case creation URL parameters และข้อมูลที่จำเป็นสำหรับ CRM Call Pop-up แบ่งเป็น Interaction Data, Customer Profile Data (ANI, lang, name, photo, email), และ Agent Profile Data (AgentID, name, extension/WebRTC name)

***Scope / Context***

- เป็นการหารือภายในเพื่อกำหนดทิศทางการยืนยันตัวตนของ CC Super App รองรับทั้ง Keycloak แบบมาตรฐานและ Genesys Cloud สำหรับลูกค้าที่ใช้ 3rd party contact center
