- นิยาม controlled vocabulary ของหมวดหมู่: Place ใช้ enum ปิด 3 ค่า (องค์กรเป็นเจ้าของข้อมูลผ่านหน้า admin), Device ใช้ตัวแปลงจากค่า `deviceType` ซึ่งเป็น free text แล้ว resolve เป็นหมวดหมู่หรือ `null` เมื่อไม่ตรงค่าที่รู้จัก — เลือก `null` แทนหมวดหมู่ default โดยเจตนา เพื่อไม่ให้ marker ผิดประเภทขึ้นบนแผนที่ผู้สั่งการ
- สร้างชุด marker symbol ต่อหมวดหมู่ (สีคงที่ + glyph บนกรอบ 24x24 + halo ตอนถูกเลือก) พร้อม builder แบบ ArcGIS autocast และ export shared token (path/สี/ขนาด) สำหรับให้ layer ของ Longdo และ MapTiler วาด glyph เดียวกันจาก SVG โดยไม่ drift ออกจากกัน — โครงเดียวกับ `staffSymbols.ts`
- ขยาย prop ของคอมโพเนนต์แผนที่ (`AddressMapProps`) ให้รับ `places` / `devices` พร้อม flag แสดงผล, id ที่เลือก และ callback รายงานการคลิก โดยยึดสัญญาเดิม “state อยู่ที่ผู้เรียก คอมโพเนนต์วาดตามที่ส่งมาและรายงานการคลิกกลับ” — คลิก Place เป็นข้อมูลอย่างเดียว ไม่เขียนกลับเข้าเคส ส่วนคลิก Device ผู้เรียกจะตั้ง `caseState.iotDevice` เป็น id ของอุปกรณ์นั้น
- เพิ่ม i18n key ของ label หมวดหมู่ Place และ Device ครบทั้งสามภาษา (en/th/cn)

**Outcome**

### CRUD Action-Permission Gating

**Spending Hour:** 0.75 hr.

**Activity**
- เพิ่ม prop `actionPermission` (optional) ให้ `EnhancedCrudContainer` และส่งต่อผ่าน `TableView` / `ClickableTableRow` / `ClickableCard`
- เมื่อกำหนดค่านี้ ปุ่ม create และ action รายแถว (view / update / delete) จะ gate ด้วย permission string ตัวเดียวที่ระบุ แทนคู่ `${module}.${action}` ที่ gate แบบเดิม derive ให้
- caller เดิมที่ส่งแค่ `module` ไม่ได้รับผลกระทบ

**Scope / Context**
- โมดูล core ส่วนคอมโพเนนต์ CRUD ที่ใช้ร่วมกันทุกหน้า Admin
- รองรับหน้าจอที่ทั้ง route ถูก gate ด้วย permission หยาบตัวเดียวอยู่แล้วและไม่มี permission family `${module}.*` ราย entity เช่น หน้า Place / Case Result ที่ gate ด้วย `organization_settings.manage`
- เป็นงาน infrastructure ล้วน ไม่มีการเปลี่ยนพฤติกรรมที่ผู้ใช้เห็นได้ด้วยตัวเอง จึงไม่มี changelog entry แยก

**Outcome**
- หน้า CRUD ใหม่ที่ไม่มี permission family ของตัวเอง สามารถ gate ทุก action ด้วย permission เดียวได้โดยไม่ต้องเพิ่มโค้ดเฉพาะหน้า
- จุดเรียกใช้ `EnhancedCrudContainer` เดิมทั้งหมดทำงานตามเดิม
- repo type-check (`tsc -b`) ผ่านทั้งก้อน

**Daily Estimated Effort:** 8 hr. / 8 hr.
