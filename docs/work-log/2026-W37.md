- นิยาม controlled vocabulary ของหมวดหมู่: Place ใช้ enum ปิด 3 ค่า (องค์กรเป็นเจ้าของข้อมูลผ่านหน้า admin), Device ใช้ตัวแปลงจากค่า `deviceType` ซึ่งเป็น free text แล้ว resolve เป็นหมวดหมู่หรือ `null` เมื่อไม่ตรงค่าที่รู้จัก — เลือก `null` แทนหมวดหมู่ default โดยเจตนา เพื่อไม่ให้ marker ผิดประเภทขึ้นบนแผนที่ผู้สั่งการ
- สร้างชุด marker symbol ต่อหมวดหมู่ (สีคงที่ + glyph บนกรอบ 24x24 + halo ตอนถูกเลือก) พร้อม builder แบบ ArcGIS autocast และ export shared token (path/สี/ขนาด) สำหรับให้ layer ของ Longdo และ MapTiler วาด glyph เดียวกันจาก SVG โดยไม่ drift ออกจากกัน — โครงเดียวกับ `staffSymbols.ts`
- ขยาย prop ของคอมโพเนนต์แผนที่ (`AddressMapProps`) ให้รับ `places` / `devices` พร้อม flag แสดงผล, id ที่เลือก และ callback รายงานการคลิก โดยยึดสัญญาเดิม “state อยู่ที่ผู้เรียก คอมโพเนนต์วาดตามที่ส่งมาและรายงานการคลิกกลับ” — คลิก Place เป็นข้อมูลอย่างเดียว ไม่เขียนกลับเข้าเคส ส่วนคลิก Device ผู้เรียกจะตั้ง `caseState.iotDevice` เป็น id ของอุปกรณ์นั้น
- เพิ่ม i18n key ของ label หมวดหมู่ Place และ Device ครบทั้งสามภาษา (en/th/cn)
