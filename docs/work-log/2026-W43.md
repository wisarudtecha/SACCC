**Activity**

- แก้ไข logic "select all" บน header checkbox ให้นับเฉพาะ row ที่ยังไม่ถูกมอบหมาย ป้องกันกรณี search result เป็นแต่เจ้าหน้าที่ที่มอบหมายแล้วแล้ว header แสดงสถานะผิด
- สร้าง `CasePreviewPopover.tsx` สำหรับแสดง preview ของ case เมื่อคลิก case number ในรายการ Assigned Cases ของแต่ละเจ้าหน้าที่ โดยแสดงข้อมูลจาก entry ที่มีอยู่ก่อน และ fallback ไป fetch เพิ่มเติมเฉพาะ bare entry (มีแค่ caseId)
- เพิ่ม field `units` ใน return value ของ `useStaffPositions` เพื่อ expose raw roster ก่อน toStaffMarkers ตัด field ออก ทำให้ map consumer สามารถอ่าน embedded workload ได้โดยไม่ต้อง fetch ซ้ำ
- อัปเดต dispatch types (`UnitWorkloadFields`, `UnitWithWorkload`) และ dispatch API (`getUnit`) ให้สะท้อน contract ใหม่ที่ backend ส่ง workload มาด้วย
- เพิ่มคำแปลภาษาไทย อังกฤษ และจีน สำหรับ label ของ Case Preview และ mention toast

**Scope / Context**

- เป็นการเปลี่ยนแหล่งข้อมูล workload ตามแผนที่ backend ย้ายข้อมูลจาก endpoint แยก (`POST /units/workload`) มาฝังไว้ใน response ของ getUnit (`/dispatch/{caseId}/units`) โดยตรง
- adapter pattern ถูกเลือกใช้เพื่อให้ UI consumer (workloadRank, OfficerWorkloadCell, OfficerAssignedCasesCell, staffFilter) ไม่ต้องเปลี่ยนแปลง — แค่เปลี่ยน data source
- Case Preview เป็นความต้องการเพิ่มเติมจาก dispatcher ที่ต้องการตรวจสอบรายละเอียด case ที่เจ้าหน้าที่รับอยู่ โดยไม่ต้องออกจากหน้า assign officer

**Outcome**

- modal มอบหมายเจ้าหน้าที่โหลดเร็วขึ้นเนื่องจากไม่ต้อง fetch workload แยกอีกครั้งหลัง roster มา
- dispatcher สามารถคลิกดู preview ของ case ในรายการ Assigned Cases ได้ทันที โดยไม่ต้อง navigate ออกจากหน้า
- เจ้าหน้าที่ที่มอบหมายแล้วยังคงแสดง workload ในรายการ แต่ไม่สามารถเลือกซ้ำได้ ลดความสับสนในการ dispatch

**Activity**

- เพิ่มคำแปล `common.mention_toast` ครบทั้ง 3 ภาษา

**Scope / Context**

- เป็นส่วนขยายของฟีเจอร์ @mention ในคอมเมนต์ case ที่เพิ่ม notification แบบ real-time เมื่อมีคน mention เรา
- ใช้ websocket event `MENTION` ตาม contract ที่ backend กำหนด (welcome-case docs/events/mention-event-contract.md)
- toast onClick เป็น infrastructure change ที่ทำให้ toast ทั่วทั้งแอปสามารถ link ไปยังหน้าอื่นได้ในอนาคต ไม่จำกัดเฉพาะ mention

**Outcome**

- เมื่อมีคน @mention เราในคอมเมนต์ case จะได้รับ toast แจ้งเตือนทันที พร้อมชื่อผู้ mention และ caseId
- คลิกที่ toast แล้วระบบ navigate ไปยังหน้า case นั้นโดยอัตโนมัติ
- ระบบ toast รองรับการทำงานแบบ clickable สำหรับ use case อื่นในอนาคต
