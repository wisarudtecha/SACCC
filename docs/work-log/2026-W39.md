### Thailand Nationwide Boundary Data Regeneration

**Spending Hour:** 2.5 hr.

**Activity**
- เขียนสคริปต์ (`build-thailand-boundaries.mjs`) แปลงข้อมูลขอบเขตการปกครองระดับจังหวัด/อำเภอทั้งประเทศจาก GeoJSON ดิบ ให้เป็น TopoJSON และแบ่งไฟล์ระดับอำเภอตามจังหวัด เพื่อลดขนาดไฟล์ที่ต้องโหลดต่อครั้ง
- ปรับ `boundarySource.ts` และ `useAdminBoundaryLayers.ts` ให้อ่านข้อมูลจากไฟล์ที่สคริปต์สร้างขึ้นแทนข้อมูลตัวอย่าง (placeholder) เดิมที่ครอบคลุมพื้นที่จำกัด
- เพิ่ม dependency `topojson-client` / `topojson-server` สำหรับใช้ในสคริปต์

**Scope / Context**
- ข้อมูลขอบเขตเดิมเป็นแค่ placeholder ครอบคลุมพื้นที่จำกัด ไม่พอสำหรับใช้งานจริงทั่วประเทศ
- สคริปต์รันแบบ manual แล้ว commit ผลลัพธ์เข้า repo เพราะ repo นี้ไม่มี CI/build step ที่รันสคริปต์นี้ให้อัตโนมัติ

**Outcome**
- Layer ขอบเขตการปกครองบนแผนที่ครอบคลุมทั้งประเทศไทยแล้ว ไม่ใช่แค่พื้นที่ตัวอย่างเดิม
- ขนาดไฟล์ที่ต้องโหลดต่อจังหวัดเล็กลงมากเมื่อเทียบกับการโหลดข้อมูลดิบทั้งประเทศ

**Daily Estimated Effort:** 8 hr.
