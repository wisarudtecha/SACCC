### Article Content Editor — Table Editing & Media Lightbox

**Spending Hour:** 5 hr.

**Activity**
- เพิ่มความสามารถแทรกตารางในตัว rich text editor ของหน้าสร้าง/แก้ไขบทความ พร้อมเมนูจัดการตาราง (แทรก/ลบแถว-คอลัมน์, รวม/แยกเซลล์, กำหนดเส้นขอบและสีพื้นเซลล์) ผ่าน context menu คลิกขวา
- ปรับการวางข้อมูล (paste) จาก Excel หรือหน้าเว็บอื่นให้คงโครงสร้างตารางและสไตล์ไว้ แทนที่จะสูญเสียรูปแบบเดิม
- เพิ่มการปรับขนาดรูปภาพในเนื้อหาบทความด้วยการลากมุมรูป
- เพิ่มฟีเจอร์ lightbox สำหรับหน้าดูรายละเอียดบทความ ให้คลิกที่รูปภาพ วิดีโอ หรือ embed แล้วเปิดดูแบบเต็มขนาดได้ ปิดด้วยปุ่ม Esc หรือคลิกนอกกรอบ
- เพิ่มข้อความแปล (TH/EN/CN) สำหรับเมนูจัดการตารางใน editor และแก้ label "Reserve Date" เป็น "Receive Date" ให้ตรงกับความหมายจริงของฟิลด์

**Scope / Context**
- อยู่ในส่วนโมดูล KMS (Knowledge Management) หน้าสร้าง/แก้ไขบทความ (ArticleCreateForm) และหน้าแสดงรายละเอียดบทความ (ArticleDetailContent) ซึ่งก่อนหน้านี้ editor รองรับเฉพาะข้อความ/ลิงก์/รูปภาพ/วิดีโอพื้นฐาน ยังไม่มีความสามารถทำตาราง
- เป็นการต่อยอด rich text editor ที่เขียนเองภายใน (ไม่ได้ใช้ library ภายนอก) จึงต้องเขียนตรรกะจัดการ DOM ของตาราง (คำนวณ grid, colSpan/rowSpan, การเลือกช่วงเซลล์แบบ Excel) เอง

**Outcome**
- ผู้เขียนบทความสามารถสร้างและจัดการตารางในเนื้อหาบทความได้ครบวงจรโดยไม่ต้องออกจาก editor และวางตารางจาก Excel ได้โดยไม่เสียโครงสร้าง
- ผู้ใช้ที่เปิดอ่านบทความสามารถดูรูป/วิดีโอ/embed แบบเต็มขนาดได้สะดวกขึ้น
- ยังไม่ได้ทดสอบกับข้อมูลจริงบนหน้าจอในรอบนี้ (ไม่ได้รัน dev server) ควรตรวจสอบการทำงานของตารางและ lightbox บนเบราว์เซอร์จริงก่อนขึ้น production

### Article Visibility Date Picker Fix

**Spending Hour:** 1.5 hr.

**Activity**
- แก้ปัญหา date picker ของ Start Date / End Date ในแท็บ Visibility ของฟอร์มบทความ ที่ popup ปฏิทินเด้งกลับไปแสดงเดือน/วันปัจจุบันทุกครั้งหลังเลือกวันที่ เนื่องจากไม่ได้ควบคุม state การเปิด/ปิดและค่าที่ picker ชี้อยู่แยกจากค่าที่บันทึกจริง
- เพิ่มการเช็คว่า End Date ต้องไม่น้อยกว่า Start Date โดย disable วันที่ก่อนหน้า Start Date ใน picker และล้างค่า End Date อัตโนมัติถ้า Start Date ใหม่มากกว่า End Date เดิม

**Scope / Context**
- อยู่ในฟอร์มสร้าง/แก้ไขบทความ (VisibilityTab) ส่วนกำหนดช่วงเวลาที่บทความจะแสดงผล เป็นบั๊กที่กระทบการใช้งานจริงเมื่อผู้ใช้พยายามแก้ไขวันที่ที่เลือกไว้แล้ว

**Outcome**
- ผู้ใช้เลือกวันที่ในแท็บ Visibility ได้ตามที่ตั้งใจโดย popup ไม่กระโดดกลับ และไม่สามารถตั้งค่า End Date ที่ขัดแย้งกับ Start Date ได้อีกต่อไป
