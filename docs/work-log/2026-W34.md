### Appointment Type Management

**Spending Hour:** 3 hr.

**Activity**
- สร้างหน้าจัดการ Appointment Type ใหม่ทั้งหน้า รองรับสร้าง แก้ไข ลบ และสลับสถานะ active/inactive พร้อม metrics สรุปจำนวนรายการ เพิ่ม route ใหม่ `/appointment-types` ในแอป cc และเมนูใน SuperSidebar/SuperTopbar
- แก้บั๊กที่ endpoint สร้าง/แก้ไข/ลบ appointment type ถูกประกาศเป็น RTK Query "query" แทนที่จะเป็น "mutation" ทำให้การกดบันทึกไม่ได้ยิง request ไปที่ server จริงๆ (ข้อมูลไม่เคยถูกบันทึก)
- ปรับ mapping GraphQL ของ appointment type ให้แยก method ต่อ path ให้ถูกต้อง (ก่อนหน้านี้ path เดียวกันแมพ POST ไปเป็น query ผิดประเภท) และเพิ่ม PUT ให้ตรงกับที่ REST endpoint ใช้จริง
- ปรับ EnhancedCrudContainer และ MetricsView ให้รองรับ module "appointment" และ type ตัวเลขสรุปของ appointment type

**Scope / Context**
- เป็น pain point เดิมที่หน้าจัดการ appointment type ยังไม่เคยถูกเปิดใช้งานจริง เมื่อลองเปิดใช้งานพบว่าการบันทึกไม่ทำงานเพราะ hook ที่ generate จาก query ไม่ใช่ mutation
- อยู่ในโมดูล CMS ส่วน Contacts และแชร์ layout เดียวกับหน้า admin CRUD อื่นๆ ผ่าน EnhancedCrudContainer

**Outcome**
- ผู้ดูแลระบบสามารถสร้าง แก้ไข ลบ และเปิด/ปิดการใช้งาน appointment type ได้จริงจากหน้าจอนี้ ข้อมูลถูกบันทึกไปยัง server และรายการรีเฟรชอัตโนมัติหลังบันทึก
- เมนูเข้าถึงหน้านี้พร้อมใช้งานใน Contacts ทั้งบน sidebar และ topbar
