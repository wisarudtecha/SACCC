## Activity (สิ่งที่ทำ)
- ตรวจสอบสิทธิ์การใช้งาน (entitlement) ของบริการ ArcGIS World Route และ ClosestFacility จริงกับ API key ที่ใช้งานอยู่ (ยิง request ทดสอบตรงไปยัง ArcGIS) เพื่อยืนยันว่าฟีเจอร์ไหนทำได้จริงก่อนเริ่มเขียนโค้ด
- พัฒนาโหมด "Smart Routing Engine" และ "ETA/TTL Dashboard" บนการ์ดเจ้าหน้าที่ในแผนที่เคส: ปุ่มคำนวณเส้นทางแบบ manual (ไม่คำนวณอัตโนมัติ), วาดเส้นทางบนแผนที่, แสดงระยะทาง เวลาที่ใช้เดินทาง เวลาถึงโดยประมาณ (ETA) และเวลาที่เหลือ (TTL) พร้อมระบบแคชผลลัพธ์ตามตำแหน่งและ cooldown 10 วินาที
- แก้ไขปัญหาความแม่นยำของเวลาเดินทาง โดยเพิ่มการคำนวณแบบอิงสภาพจราจรจริง (traffic-aware) แทนเวลาบนถนนโล่งซึ่งพบว่าคลาดเคลื่อนได้มากกว่า 40% ในพื้นที่กรุงเทพฯ
- พัฒนาให้กลุ่มเจ้าหน้าที่ที่อยู่ใกล้กัน (cluster) แสดงระยะทาง/เวลาเดินทางของทุกคนพร้อมกันทันทีที่เปิดรายการ โดยไม่ต้องกดปุ่ม และไม่วาดเส้นทางบนแผนที่ในมุมมองนี้ พร้อมระบบแคช 90 วินาทีเพื่อลดการเรียกใช้บริการแผนที่ซ้ำโดยไม่จำเป็น
- แก้ไขปัญหาป้ายชื่อเขตการปกครอง (จังหวัด/เขต/แขวง) บนแผนที่บดบังไอคอนกลุ่มเจ้าหน้าที่และตัวเลขจำนวนคน โดยให้ซ่อนป้ายชื่ออัตโนมัติเมื่อเปิดชั้นข้อมูลเจ้าหน้าที่
- เพิ่มการแสดงสถานะของเจ้าหน้าที่ที่เกี่ยวข้องกับเคสที่กำลังดูอยู่ (เช่น ถูกสั่งการ / ถึงที่เกิดเหตุ) ควบคู่กับสถานะการปฏิบัติหน้าที่ทั่วไป ทั้งในการ์ดเจ้าหน้าที่รายบุคคลและรายการกลุ่ม
- ตรวจพบและแก้ไขบั๊กที่ทำให้การถอนเจ้าหน้าที่ออกจากเคส (cancel unit) ล้มเหลวเงียบ ๆ เนื่องจากฟังก์ชันอ้างอิงค่าที่ยังไม่ถูกอัปเดต (stale closure) ทำให้ไม่ได้ส่งเลขที่เคสไปกับคำสั่ง
